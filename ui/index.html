What is Fhenix CoFHE?

Fhenix brings Fully Homomorphic Encryption to EVM smart contracts. FHE allows computation on encrypted data — the contract never sees raw values, only ciphertexts. The CoFHE coprocessor handles all encrypted operations off-chain.

This suite demonstrates three real-world use cases: sealed auctions, private governance, and confidential DeFi — all running on the same FHE stack with 33 passing tests.
